📦 Aula 13 — Containerização com Docker

1

Respostas iniciais

Ativação do conhecimento prévio sobre containers, Docker e reprodutibilidade de APIs de ML.

2

VM x Container

Máquina Virtual virtualiza o SO completo (pesada). Container isola apenas o processo (leve e rápido).

3

Projeto criado no Google Colab

Estrutura de pastas: api/ models/ reports/ logs/

4

API FastAPI criada — api/main.py

GET/
Página inicial da API
GET/health
Verificação de saúde da API
POST/predict
Predição de falha em motor industrial
5

Dockerfile criado

FROM python:3.11-slim WORKDIR /app COPY requirements.txt . RUN pip install --no-cache-dir -r requirements.txt COPY . . EXPOSE 8000 CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]
6

Arquivos de containerização

.dockerignore — exclui arquivos desnecessários da imagem

.env.example — documenta variáveis de ambiente sem expor segredos

docker-compose.yml — simplifica o comando de execução

Conceitos de observabilidade

Boas práticas de segurança aplicadas
